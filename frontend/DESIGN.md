# Interface do VellumHub

- Aplique variáveis de tema de `tokens.json` para cores e use os estilos do componente para os estados visuais.
- Edite a fonte DTCG e gere o CSS com `npm run tokens`.
- Preserve foco visível, nomes acessíveis e alvos de interação de pelo menos 44 px.
- Use elementos HTML nativos para botões, campos e seleções. Prefira controles com nome visível e texto direto.
- Use as capas do catálogo. A capa de fallback é decorativa e o título também aparece como texto.
- Em telas de livros e preferências, mantenha estado de erro e sucesso próximo ao controle acionado.
