This local documentation viewer does not contact application APIs or require credentials. It needs a local HTTP server (from the repository root: python3 -m http.server 8000) because browsers restrict file:// fetch. Diagram graphics require network access to the pinned Mermaid package; if unavailable, the source is shown in plaintext. C4 diagrams are logical code-level architecture, not infrastructure deployment proof. Cache runs locally but production flags remain OFF.
